# Frontend Instructions

- Use semantic HTML and preserve keyboard/focus behavior.
- Every server-backed view implements loading, error, empty, and success states.
- Use the shared API client; do not reproduce wire types in feature components.
- Treat client-side role checks as presentation only; the API enforces access.
- Keep Teams host detection and authentication inside application adapters.
- Verify TypeScript, component behavior, responsive layout, and production build.
